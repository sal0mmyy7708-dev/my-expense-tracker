# My Expense Tracker

A simple expense tracking application built with Python.

## Features
- Add, edit, and delete expenses.
- Search and filter expenses.
- View monthly expense reports.
- View expenses by category.
- Set a monthly budget.
- Display expense charts.
- Password-protected access.

## Technologies Used
- Python
- Tkinter
- Matplotlib
- JSON

## About
This is a beginner Python project created to practice programming, graphical user interfaces, and saving data in files.
